Angular component debugger

Details

The Chrome extension, Angular Outliner, enhances the visualization of Angular application components by drawing borders around them, making it easier to grasp the application's structure and component relationships.

For Angular 10+ components in debug mode. It works on http://localhost:4200 only.

You may try to set host: { display: block; }. Sometimes it helps to draw more accurate border.
